# 公募基金交易拥挤度与集中度仪表盘

> 基于**公募基金季报持仓数据 + 申万一级行业成交额数据**构建的季度更新看板。
> **完全不使用 ETF 资金流向数据**——交易拥挤度只用行业成交额与个股成交额衡量。
>
> 数据口径：主动权益基金（普通股票型 + 偏股混合型 + 灵活配置型 + 平衡型）季报前十大重仓股；
> 行业口径：申万一级 31 个行业；频率：季度；样本：2018Q1 – 2026Q2 共 34 个季度。

## 1. 快速开始

### 1.1 首次运行（三步）

```bash
cd fund_crowding_dashboard
pip install -r requirements.txt

# ① 首次：从两份原始材料生成 data/raw/ 全部规范数据文件
python tools/seed_raw_data.py

# ② 一键跑通全流程：校验 → 因子 → 回测 → 信号 → 导出
python src/update_pipeline.py

# ③ 启动看板
streamlit run app.py
```

浏览器打开 `http://localhost:8501`。

```bash
# 把新一期数据放进 data/raw/ 后：
python src/update_pipeline.py      # 重算并导出
streamlit run app.py           # 若服务已在运行，直接按 R 键刷新即可
```

## 3. 底层逻辑：为什么这样做

### 3.1 数据链条

```
公募基金季度持仓行为
      ↓  按申万一级行业汇总
行业配置比例  ──  相对沪深300行业权重  ──→  行业超配比例
      ↓                                          ↓
  集中度 HHI / CR3               相对自身历史的极端程度（Z、历史分位）
      ↓                                          ↓
   市场层面「抱团程度」              行业层面「持仓拥挤度」
                                                 ↓
                   +  行业成交额占比及其历史分位  →  交易拥挤度
                   +  个股抱团指标（持股基金数）  →  筹码拥挤度
                                                 ↓
                                     三信号共振 → 综合拥挤度
```

**本质**：机构资金边际定价权越集中，相关资产越容易被"再定价"。

### 3.1.1 数据源：Wind（机构级）

| 数据集 | Wind 取数口径 | 文件 |
|---|---|---|
| 基金重仓行业市值 | **主动权益三类**（普通股票型 + 偏股混合型 + 灵活配置型）前十大重仓股，按申万一级行业汇总，单位亿元 | `wind_industry_mv.xlsx` |
| 行业配置比例 | 上述市值 ÷ 全行业重仓市值合计 × 100% | `industry_allocation.xlsx` |
| 沪深300 行业权重 | 沪深300 成份股行业总市值 ÷ 沪深300 成份股总市值合计 | `hs300_weights_quarterly.xlsx` |
| 行业涨跌幅 / 成交额 | 申万一级行业指数季度区间值 | `sw_industry_returns.xlsx` / `sw_industry_turnover.xlsx` |

> **口径警示（本项目实际踩过的坑）**
>
> 抓取问句若写「全部公募基金」，Wind 会返回**全口径**（含债券型、指数型、货币型、
> FOF、QDII），使重仓股市值虚高约 82%，严重稀释持仓结构。
> **必须显式写明「普通股票型、偏股混合型、灵活配置型」三类。**
>
> 另：Wind 返回的「行业总市值占比」有两种分母（占沪深300 / 占全部A股），
> 靠**各期合计是否 ≈ 100%** 判别。本项目曾误用 A股口径（合计仅 55–57%），已修正。
>
> 完整审计见 [`data/raw/data_quality_report.md`](data/raw/data_quality_report.md)。

### 3.2 四条必须理解的原则

1. **季报是低频高信息量数据。** 前十大重仓股是可得的最及时持仓数据。它**低估分散型行业**，
   但**口径一致时横向可比**——所有行业都用同一套口径，所以横截面比较是有效的。

2. **拥挤度不是单一指标，而是三层合成。**
   - **持仓拥挤**：行业超配比例、HHI、CR；
   - **交易拥挤**：行业成交额占全市场比重及其分位（本项目**不用 ETF 资金流**）；
   - **筹码拥挤**：龙头个股持股基金数、Top20 持仓市值占比。

3. **拥挤是风险信号，不是择时信号。** 高拥挤 ≠ 必然下跌，而是"市场重新审视定价"的
   **概率上升**。本项目把它定位为**风险描述与压力测试输入**，不是买卖信号。

4. **无未来函数是硬约束。** 第 T 期因子只能使用第 T 期及之前已披露数据。
   季报披露约滞后 15 个工作日，故 T 期持仓在 T+1 季度首月即可获得，
   T → T+1 是可交易窗口（稳健性另测 T → T+2）。

### 4.3 五项增强校验（本项目追加）

| 规则 | 内容 | 当前结果 |
|---|---|---|
| **R6** | 用配置比例独立复算 HHI / CR3 / CR5 / CR10，与 `industry_cr_hhi.xlsx` 逐期比对 | 最大绝对差 < 1e-6，**完全一致** |
| **R6b** | 反解 HHI 标准化公式 = `(HHI − 1/31) / (1 − 1/31)` | 公式确认 |

## 5. 因子体系 F1–F11

> 全部因子的阈值为**扩窗（无前视）**口径：`s.shift(1).expanding(min_periods=8)`。
> 因此前 8 个季度（2018Q1–2019Q4）没有 Z / 分位 / P90 取值，返回 NaN。
> **这是刻意设计，不是缺陷**——避免用未来信息定义"极端"。

### F1　行业超配比例

- **原理**：衡量主动权益基金对某行业的**主动偏离程度**。
- **公式**：`超配(i,t) = 行业 i 在 t 期配置比例(%) − 行业 i 在沪深300中的权重(%)`
- **判断**：> +5% 显著超配；< −5% 显著低配
- **经济含义**：正值 = 机构相对基准看多；偏离越大，机构定价权越集中。

### F2　超配 Z-score（核心）

- **原理**：消除行业间基准差异，衡量当前超配**相对自身历史**的极端程度。
- **公式**：`Z(i,t) = [超配(i,t) − mean(超配(i, 2018Q1..t−1))] / std(超配(i, 2018Q1..t−1))`
- **判断**：Z > 2.0 极度拥挤；Z > 1.5 拥挤；Z < −1.5 显著低配
- **注意**：必须扩窗，**不使用未来数据**。

### F3　超配历史分位（核心）

- **原理**：当前超配在历史分布中的百分位，**不依赖分布假设**（比 Z 更稳健）。
- **公式**：`分位(i,t) = percentile_rank(超配(i,t), 超配(i, 2018Q1..t−1))`
- **判断**：≥ 90 极度拥挤；75–90 偏拥挤；≤ 10 显著低配

### F4 / F4b　超配动量 / 动量 Z

- **原理**：捕捉拥挤度的**边际变化**。超配环比上升越快，资金正在加速集中。
- **公式**：`动量(i,t) = 超配(i,t) − 超配(i,t−1)`；
  `动量Z(i,t) = [动量(i,t) − mean(动量历史)] / std(动量历史)`
- **判断**：动量 > 0 资金流入；动量Z > 1.0 加速流入

### F5　行业 HHI

- **原理**：赫芬达尔-赫希曼指数，衡量行业配置集中度。HHI 越大，有效配置行业数越少。
- **公式**：`w(i,t) = 配置比例 / 100`（**必须转小数**，否则放大 10000 倍）；
  `HHI(t) = Σ w(i,t)²`；标准化 `= (HHI − 1/31) / (1 − 1/31)`
- **判断**：< 0.05 低；0.05–0.10 中；0.10–0.15 高；> 0.15 极高
- **验证**：2026Q2 HHI = 0.2314，电子 43.24% → 0.4324² ≈ 0.1870，通信 16.92% → 0.0286，其余累加 ≈ 0.0158，合计 0.2314 ✓

### F6　CR3 / CR5 / CR10

- **公式**：`CRn(t) = 前 n 大行业配置比例之和`
- **判断**：CR3 > 60% 高度集中
- **验证**：2026Q2 CR3 = 67.53%，CR5 = 79.15%，CR10 = 90.25%（由配置比例独立复算，最大绝对差 < 1e-13）

### F7　个股集中度（筹码拥挤）

- **子因子**：Top20 平均持股基金数、Top20 持仓市值占比、持股基金数 ≥100 / ≥50 / ≥20 的个股数、前十大重仓占净值比
- **判断**：任一子因子**创扩窗新高** = 筹码拥挤信号
- **重要说明**：这是**市场层面时序**指标，同一季度对 31 个行业取同一值。
  它**不能区分行业**，只描述"整体抱团程度"。因此它只进入市场层面合成与共振信号 S3，
  不进入行业横截面合成（详见 F11 说明）。

### F8　仓位代理

- **使用**：前十重仓占净值比 均值 / 中位数（**弃用「隐含股票仓位估算均值」**）
- **公式**：`仓位动量(t) = 仓位代理(t) − 仓位代理(t−1)`
- **判断**：破扩窗 P90 后关注市场回调概率
- **⚠️ 这不是真实股票仓位**，只是重仓集中度的代理。

### F9　交易拥挤度（不用 ETF，只用行业成交额）

- **子因子**：
  - `成交额占比(i,t) = 行业成交额 / 全市场行业成交额合计 × 100%`
  - `成交额占比分位(i,t)`：扩窗历史分位
  - `成交额占比加速度(i,t) = 占比(i,t) − 前4季均值(t−1)`
- **信号**：`成交额占比分位 ≥ 90 且 加速度 > 0` = 交易拥挤
- **合成**：`交易拥挤度 = 0.6 × 横截面Z(分位) + 0.4 × 横截面Z(加速度)`
- **经济含义**：成交额占全市场比重既反映资金关注度，也反映换手过热。
  占比高 + 仍在加速 = 短线资金拥挤。**完全用行业成交额构造，不依赖任何 ETF 资金流数据。**

### F10　共振得分

| 信号 | 定义 | 含义 |
|---|---|---|
| S1 | 超配分位 ≥ 90（即超配 > 扩窗 P90） | 持仓拥挤 |
| S2 | 成交额占比分位 ≥ 90 **且** 环比加速 | 交易拥挤 |
| S3 | 个股抱团指标创扩窗新高（市场层面） | 筹码拥挤 |

`共振得分 = S1 + S2 + S3`；判断：3 = 最高风险；2 = 双信号；0–1 = 无/弱。
任一信号为 NaN 时得分为 NaN（不做零填充，避免"无数据"被当成"无风险"）。

### F11　综合拥挤度

**行业层面**（权重合成，横截面 Z 标准化）：

```
综合拥挤度(行业) = Σ w_k × 横截面Z(分量_k)
```

**v2 推荐权重**：`F1 超配比例 = 0.20`、`F12 配置系数 = 0.25`、`F3 超配历史分位 = 0.15`、
`F13 筹码盈利比例 = 0.15`、`F14 ETF资金流强度 = 0.15`、`F4b 超配动量Z = 0.10`

**缺失分量自动重新归一化**：某期某行业若缺部分分量（例如 F14 只有 2026Q3 的
ETF 数据），只在**可用分量之间**按原比例重新归一化权重；可用分量 < 2 时该单元置 NaN，
避免单分量代表"综合"。这是 `weighted_z_composite()` 的核心行为。

> **v1 旧口径对照**：`F2=0.35 / F3=0.30 / F4b=0.10 / F9=0.10`，结果保留在
> `F11_综合拥挤度_旧口径对照` 列，便于比较权重调整带来的变化。
- **等权版本**：4 个分量等权
- **IC 加权版本**：权重 = 各分量截至 **t−2 期**的扩窗平均 RankIC（严格无前视）

> **⚠️ 关于原定权重中的 F7 = 0.15——已做技术性调整，理由如下：**
> F7 是市场层面时序指标，同一季度 31 个行业取同一值，是**常数列**。
> 常数列做横截面 z-score 后恒等于 0，对行业排序**零贡献**。
> 强行纳入只会制造"权重是 0.15"的假象。故：
> - 行业层面：权重在 4 个"行业内可区分"的分量间归一化；
> - F7 的权重移至**市场层面综合拥挤度**（`F11_市场综合拥挤度Z`，
>   分量 = HHI 0.30 + CR3 0.25 + 个股集中度Z 0.30 + 仓位代理Z 0.15）。

**市场层面**：

```
市场综合拥挤度Z = 0.30 × Z(HHI) + 0.25 × Z(CR3) + 0.30 × Z(个股集中度) + 0.15 × Z(仓位代理)
```

### 拥挤等级判定

| 等级 | 条件 | 含义 |
|---|---|---|
| ① 极度拥挤 | 超配分位 ≥ 90 | 再定价概率上升 |
| ② 拥挤 | Z > 1.5 | 需关注 |
| ③ 偏拥挤 | 分位 75–90 | 正常偏高 |
| ④ 显著低配 | Z < −1.5 | 可能超卖 |
| ⑤ 中性 | 其余 | — |

> **⚠️ ④⑤ 的「低配」是相对该行业自身历史的判断，不等于相对沪深300 的绝对低配。**
> 例如 2026Q2 医药生物配置 10.29%、超配 +6.19%（绝对仍是超配），
> 但 Z = −3.14、分位 = 0%——因为 2018 年它曾占 15.6%。
> 标签说的是"相对自己的历史处于极低位"，这是**时点比较**，不是**截面比较**。

## 6. 统计方法与选择理由

### 6.1 为什么用扩窗（expanding）分位，而不是全样本分位？

全样本分位在计算第 t 期分位时会用到 t 之后的观测，这是**前视偏差**。
源数据 `8-阈值与预警体系` 的 Z 值 / P90 / 历史分位就是**全样本口径**（事后阈值），
直接用于回测会高估因子有效性。本项目一律重算为 `shift(1) + expanding`，
并在 `data_validation_log.txt` 中量化了两套口径的差异。
看板顶栏保留了「全样本」开关，**仅供对照，默认扩窗**。

### 6.2 为什么用 RankIC（Spearman）而不是线性 IC（Pearson）？

- 行业样本只有 31 个，极端值（如电子超配 +17.6 pct）对 Pearson 影响过大；
- 拥挤度因子与收益的关系更可能是**单调而非线性**；
- Spearman 对单调变换不变、对异常值稳健。

### 6.3 为什么 IC 均值要用 Newey-West（滞后 2 期）做 t 检验？

RankIC 序列存在**自相关**（因子本身是持久的季度变量，相邻季度信息重叠）。
朴素 t 检验会**低估标准误、高估显著性**。Newey-West 用 Bartlett 核加权自协方差，
在滞后 2 期（约半年）下给出稳健的 t 与 p 值。本项目所有 IC 的 t 值均为 NW 调整值。

### 6.4 为什么要做分层回测？

IC 只说明"排序是否有预测力"，不说明**能否交易**。分层回测回答三个问题：
① 各层收益是否**单调**（单调性 Spearman）；② 多空组合的**年化 / 回撤 / 夏普**；
③ 剔除交易摩擦前的**理论上限**。单调性用 `Spearman(层序号, 各层平均收益)`。
**评价标准**：多空年化 > 5%，最大回撤 < 15%，夏普 > 0.5，单调性 > 0.8。

### 6.5 为什么要做事件研究？

IC / 分层是**平均效应**，事件研究是**条件效应**：
"当某个行业**首次**突破 P90 时，之后 3/6/12 个月发生了什么？"
这直接检验报告中最关键的可操作命题（"极度拥挤后回落"）。
统计量采用**中位数**（抗极端值）+ 负收益概率 + t 检验，
**且必须与无条件基准对比**——否则牛市里所有事件都是正收益，会得出错误结论。

### 6.6 稳健性检验的四个维度

| 维度 | 做法 | 回答的问题 |
|---|---|---|
| 样本内 / 外 | 2018Q1–2023Q4 vs 2024Q1–2026Q2 | 是否过拟合 |
| 市场状态 | 牛 / 熊 / 震荡（按过去 4 季沪深300 累计收益 >15% / <−10% 划分） | 是否只对特定 regime 有效 |
| 参数敏感性 | 扩窗 min_hist = 8/12/16；滚动窗口 = 8/12/16 | 是否对窗口长度敏感 |
| 正交化 | 对当期收益 / 过去4季收益 / 过去4季波动做截面 OLS，取残差 | 是否只是动量/反转/波动的代理 |

### 10.3 统计功效警示（必须诚实披露）

- 样本仅 **9–10 期**，远低于因子研究通常要求的 36 期以上；
- F11 的 p < 0.001 在 10 期样本下**极易受单期（2026Q2）极端值驱动**，须做剔除检验；
- 4 个因子同时检验，未做多重检验校正（Bonferroni 阈值应降至 0.0125）；
- **上述结论应视为"方向性证据"，而非"稳健的统计结论"。**

- **hs300 扩至 18 期**（2022Q1~2026Q2）：问句对历史期完全稳定，逐期加总=100.00%±0.02，

- **偏股混合型 15 期独立序列**（2022Q1~2026Q1，剔除异常期 2023Q2）：
  与主口径重叠期 **HHI 平均绝对差 0.0069、CR3 差 <2pct**，集中度走势与拐点完全一致；
- **长历史视角**：2022–2024 年 HHI 稳定于 0.07~0.10 低位，2025Q3 方突破至 0.10+，
  印证「集中度跃升」是**真实结构性拐点**，非口径切换或样本过短的假象。

### 10.3.1 图表洞察引擎（本轮新增）

用户要求「每一张图都要有分析、结论，并突出特征与拐点」。人工为 30+ 张图逐张写解读
既不可维护、也会随数据更新而过期。本项目的做法是**从数据本身算出特征与拐点**，
再把数字填进固定句式（`src/insights.py`）：

| 层次 | 函数 | 产出 |
|---|---|---|
| L1 序列画像 | `series_profile()` | 起点/终点/极值/单调性/趋势拟合 R²/最大单期变动 |
| L2 拐点检测 | `detect_turns()` | T1 趋势反转、T2 单期跃迁、T3 极值突破（含季度与幅度） |
| L3 结论生成 | `describe_series()` | 「特征 / 拐点 / 结论」三段式，全部由数字驱动 |
| 横截面 | `describe_cross_section()` | 头部集中、尾部、极差、首末比 |
| 综合判断 | `build_verdict()` | 一句话结论 + 5 条带证据的判断理由 + 3 个最突出特征 + 拐点清单 |

**设计纪律：**
1. 所有文字结论都由数字驱动，不写「显著上升」这类无证据表述；
2. 拐点必须给出**具体季度与幅度**；
3. 无法得出结论时返回 `None` 并说明原因，**不编造**。

拐点检测带**噪声门槛**（`noise_frac = 0.15 × 全序列最大单期变动`）——
早期版本仅用符号变化判定反转，会把 `−0.0003` 报成「趋势反转」。

## 11. 投资建议

> **前置声明：本项目不构成投资建议。以下为基于数据的方法论应用指引。**

### 11.1 可以怎么用（有证据支持的部分）

1. **把拥挤度当作"仓位约束"而非"买卖信号"**。
   组合构建时限制单个行业的**新增仓位**：对已处于"极度拥挤"的行业（分位 ≥90），
   新增敞口需额外论证，而不自动加仓。这不需要因子有预测力就成立——
   它只是**风险管理纪律**。

2. **用市场层面 HHI / CR3 做压力测试**。
   当前 HHI = 0.1897（历史最高、97% 分位）、电子单一行业 36.83%。
   可以做情景测试：**若电子回撤 30%，组合净值受多大冲击？**
   这是本项目最有价值、也最稳健的用途。

3. **把"显著低配 + 成交额分位低"作为研究候选池**（而非直接买入）。
   2026Q2 有 6 个显著低配行业，其中多个的绝对超配仍为正——
   注意区分"相对自身历史低位"与"相对基准低配"。

4. **用信号触发记录做复盘清单**。
   每次报告新一期数据时，对照 `signal_report.xlsx` 的触发记录，
   检查上期发出的预警是否兑现——**用它来校准自己的判断，而不是替代判断**。

### 11.2 不应该怎么用（证据不支持的部分）

| ❌ 不要做 | 原因 |
|---|---|
| 用"极度拥挤"直接做空或减仓 | 55 次 P90 突破事件后 12 个月中位数 **+3.36%**，方向相反 |
| 用"三信号共振"作为最强卖出信号 | 共振得分 3 后 12 个月中位数 **+10.04%**，负概率仅 14.3% |
| 相信 F2/F3 的样本外高 IC | 样本外 +0.15~+0.18 完全由 2024–2026 单边行情驱动，仅 9 个观测 |
| 把 F11 综合拥挤度当 alpha 因子 | IC_IR 仅 0.17~0.24（< 0.3 门槛），多空回撤 −23%，样本外不可复现 |
| 用 F9 交易拥挤度做独立信号 | 正交化后残差 IC 仅 −0.008，本质是价格动量的代理 |

### 11.3 一句话总结

**拥挤度是一个「气候」指标，不是一个「天气预报」。**
它能告诉你现在是"干燥易燃的季节"，但不能告诉你"明天会不会着火"。
用它来**控制下注规模**，不要用它来决定**下注方向**。

## 12. 风险提示与已知局限

### 12.1 数据口径类（必须随结论一并引用）

1. **前十大重仓口径 ≠ 全部持仓。** 季报只披露前十大重仓股，行业配置比例是
   "前十大重仓股口径"。这会**系统性低估分散型行业**（如银行、公用事业），
   **高估集中型行业**（如电子）。所有行业用同一口径，故**横向可比**，但**绝对水平有偏**。
2. **港股/非 A 股已剔除**，剔除比例约 6%。这会低估港股配置较重的行业。
3. **申万分类存在回溯偏差。** 现行 31 个申万一级行业是 2021 版分类，
   用现行分类回溯 2018 年持仓会有归类偏差。
4. **沪深300 权重为静态权重**（34 期恒定，已由配置−超配反验证）。
   实际指数成分与权重逐年变化，超配比例的绝对值因此有系统性偏移。
5. **区间涨跌幅为指数点位口径（不含股息）**，会使绝对收益略低于含息口径，
   但对行业间横向比较影响很小。
6. **成交额为区间成交额（亿元）**，来自行业指数口径，与全市场个股成交额加总口径可能略有差异。

### 12.2 方法论类

7. **样本量严重不足。** 34 个季度 → 最多 34 个 RankIC 观测；
   事件研究 55 次；三信号共振仅 26 次。**所有"不显著"的结论都可能是样本不足导致的**，
   不能等同于"已证伪"。同理，"显著"的结论也可能是偶然。
8. **扩窗口径损失前 8 期。** 2018Q1–2019Q4 没有 Z / 分位值，
   有效 IC 观测进一步降到 24–33 个。
9. **多空组合未计交易成本、未考虑融券可行性。** 报告中的多空年化是**理论上限**。
   A 股行业指数融券做空成本高、券源稀缺，**实际不可实现**。
10. **行业指数不可直接交易。** 行业层面回测结果不能直接映射到可投资产品。
11. **单一数据源、单一市场、单一周期。** 结论仅适用于 A 股主动权益基金 2018–2026 区间。

### 12.3 结论性质声明

- 本项目的核心实证结论是**"未发现显著证据支持拥挤度具有预测力"**，
  **不是"已证明拥挤度无效"**。二者的区别至关重要。
- **区分描述性结论与预测性结论**：
  - 描述性（**可采信**）：2026Q2 HHI=0.1897、CR3=63.49%、电子配置 36.83%、
    3 个行业极度拥挤、6 个行业显著低配 —— 这些是**事实**。
  - 预测性（**证据不足**）：高拥挤行业未来会跑输 —— 这需要 IC / 事件研究支持，
    而本项目的检验**未通过**。
- **当前时点的极端值无法自我检验**：2026Q2 因子没有前瞻收益，
  当前极端的结局在数据上**不可检验**。

任何引用本看板结论的场合，请一并保留：
> 数据口径＝主动权益基金季报前十大重仓股（非全部持仓）；

**份额折算（拆分/合并）必须剔除——这是最容易出错的地方。** 本期发现两次 1:2 折算：

- `512480` 于 **2026-07-02**：份额 86.89 → 173.66 亿份，单位净值 2.9318 → 1.3447

识别方法（物理正确，替代了不可靠的"整数倍"启发式）：
```
折算倍数 K = round( (累计单位净值环比) / (单位净值环比) )
```
原理：折算把份额乘 K、把单位净值除 K，但**累计单位净值不受影响**；
正常交易日两者近似相等 → K = 1。
若不处理，会把 **+116.68 亿**（512480）与 **+248.19 亿**（515880）的假净申购计入，
实际分别为 **−0.16 亿** 与 **−5.09 亿**。

## V2-2 因子体系优化

### F12 配置系数

- **原理**：相对**基准权重**的偏离倍数，与 F1（差值）、F2/F3（相对自身历史）互补。
- **公式**：`配置系数(i,t) = 配置比例(i,t) / 沪深300权重(i,t)`
- **判断**：> 2.5 极度拥挤；1.8~2.5 拥挤；< 0.5 显著低配
- **边界**：基准权重为 0 的行业（纺织服饰、轻工制造、环保、综合）**无定义 → NaN**，
  已在文档标注；合成时按可用分量重新归一化。

### F13 筹码盈利比例 ⚠️ **指数层面代理**

- **目标口径**：行业成分股中「现价 > 持仓成本」的市值占比（需逐股持仓成本）。
- **本项目口径（可算代理）**：
  1. 用季度涨跌幅累乘得到行业指数相对点位 `P`（P₀ = 100）；
  2. 取滚动窗口（主口径 12 季度）的成交额 `T_s` 作为该价位的筹码量；
  3. `筹码盈利比例 = Σ_{P_s < P_t} T_s / Σ_{s∈window} T_s × 100%`
- **含义**：滚动窗口内存量筹码中，建仓价低于现价的比重。高＝获利盘拥挤（易抛压），
  低＝深度套牢（潜在反转）。
- **对照口径**：`F13b_筹码盈利比例_全历史`（自 2018Q1 起全历史）。
- **⚠️ 这不是成分股加权口径**，已在 README、看板与 `provenance` 三处标注。

### F14 ETF资金流强度

- **公式**：`资金流强度(%) = Σ期内净申赎(亿元) / 期初AUM(亿元) × 100`，AUM = 复权份额 × 复权净值。
- **覆盖**：仅 2026Q3、4 只行业 ETF（详见 V2-1(2)）。
- **⚠️ 与季报持仓相差一个季度**：持仓数据截至 2026Q2，ETF 日度是 2026Q3。
  两者**不可直接相乘**。因此 F14 **不进入历史 F11 合成**（历史各期 F14 为 NaN，
  权重自动重新归一化），而是作为**独立的当前状态信号**呈现（对应持续跟踪模型的"快层"）。

### F11 综合拥挤度权重调整 ✅

原：`F2=0.35, F3=0.30, F4b=0.10, F7=0.15, F9=0.10`
→ 新：`F1=0.20, F12=0.25, F3=0.15, F13=0.15, F14=0.15, F4b=0.10`

**两个必须说明的技术性调整**：

1. **F7 已移出行业合成**。F7（个股集中度）是**市场层面时序**指标，同季度 31 个行业
   取同一值，是常数列；常数列做横截面 z-score 恒为 0，对行业排序**零贡献**。
   故其权重移至**市场层面**综合拥挤度（`F11_市场综合拥挤度Z`）。
2. **F9 已被替换**。新权重中不含 F9（交易拥挤度，原本用行业成交额构造）。

   且其信息已部分被 F13（成本线）、F12 覆盖。F9 仍完整保留在因子面板中供参考。

## V2-4 统计方法升级 ✅ 全部完成

### Bootstrap 置信区间

- **块（moving-block）抽样**，`block = 4 季度`（≈1 年），`N = 1000`，随机种子固定
  为 `20260930` → **结果可复现**。
- **为什么用块抽样**：RankIC 序列存在自相关（因子是持久变量）；逐点重抽会破坏时序
  结构、低估标准误。块抽样保留块内自相关。
- **结果**：IC 均值 95% 置信区间**不包含 0 的因子数 = 0 / 10**。
  → **没有任何因子的 IC 均值在 5% 水平上显著异于 0**，所有 IC 结论都无法排除抽样噪声。

### 因子衰减分析

- 因子是季度频率，故"滚动 252 个交易日"等价于**滚动 4 个季度**。
  同时给出 4 / 8 / 12 季度三档窗口（≈252 / 504 / 756 交易日）。
- 输出每个因子的滚动 IC 均值、滚动 IC_IR、滚动胜率，以及"最新窗口"读数。

### FCI 因子拥挤指数

```
FCI = ( z_空头集中度 + z_ETF资金流 + z_因子相关性 ) / 3
```

| 分量 | 定义 | 含义 |
|---|---|---|
| z_空头集中度 | 每期取综合拥挤度**最低**的 1/3 行业（"空头腿"），其配置比例的 HHI，再做时序扩窗 z | 空头腿越集中 → "低拥挤"这一侧越拥挤 → 因子越易被反向踩踏 |
| z_ETF资金流 | 全市场 ETF 净申赎强度（Σ净申赎 / Σ期初AUM）的时序扩窗 z | 资金越集中涌入 → 因子越拥挤 |
| z_因子相关性 | F11 与其余候选因子的平均 \|Spearman\| 秩相关，再做时序扩窗 z | 与既有因子越冗余 → 因子本身越拥挤 |

**⚠️ 局限**：ETF净申赎强度仅 2026Q3 有数据，故历史期 FCI 为**双分量**口径
（空头集中度 + 因子相关性，需 ≥2 个分量才出值），已在看板标注。

## R1-2 本轮发现的新问题（含一个自己的 Bug）

### ❗ 问题 1（严重，已修复）：正交化残差因子是**假的**

上一版我把 `ind["R_F2_超配Z_残差"]` 等当作"正交化后仍有效"的证据，
但本轮加了一致性检查发现：

```
F2 与 R_F2 的 IC 完全相同（都是 0.0844），且 Bootstrap CI 一模一样。
```

**根因**：`_ctrl = [ind[c] for c in _ctrl_names if c in ind]` 被放在
`ind["CTRL_第t期收益"] = ...` **之前**执行 → `_ctrl` 为空列表 →
回归退化为"仅减去逐期截面均值"。而 **Spearman 对逐期常数平移不变**，
所以 IC 一模一样，**bug 静默通过**。

**修复**：把残差计算块移到 CTRL 定义之后，并加断言：
```python
assert len(_ctrl) == len(_ctrl_names), f"正交化控制变量缺失：{_ctrl_names}"
```
修复后 F2 与 R_F2 的平均绝对差为 **0.6744**（确实正交化了）。

> 教训：**"因子没变化"本身就是一个应该被断言捕获的信号**。
> 已把该断言写入代码，避免复发。

### 最强新因子：F15 拥挤背离

**构造**（源于"方向分裂"诊断，而非拍脑袋）：
```
F15(i,t) = z_cs(超配比例) − z_cs(超配Zscore)
```
含义：**绝对超配高、但相对自身历史还不极端** → **新增的拥挤**
（新资金刚进来、历史分位还没抬起来）→ 理论上最危险。

**为什么可信（三条独立证据）**：

1. **零自由参数**。F15 只是两个 z-score 相减，**没有任何拟合参数的**，
   因此不存在参数过拟合；唯一的"设计自由度"是选择哪两个 z 相减。
2. **三段子样本全部同号**：−0.0502 / −0.1983 / −0.1248（胜率 44.4% / 25.0% / 12.5%）
   —— 分段越靠后越强，**不是靠某一段撑起来的**。
3. **NW 滞后阶数 0/1/2/4/8 全部显著**：t = −2.31 / −2.51 / −2.54 / −2.71 / −3.14。
4. **换手率最低（42.9%）**，扣成本影响最小（−13.63% → −14.24%）。
   注：表中按"高−低"惯例显示为负，**实际可交易方向为反向**
   （低 F15 − 高 F15 ≈ **+13.6%/年**）。

> ⚠️ **必须标注的方法学局限**：F15 的构造灵感来自**观察全样本上 F1 与 F2 的符号**，
> 因此它的样本内 IC 存在乐观偏差。目前的缓解证据是"三段子样本 + 零自由参数"，
> 但这**不等于真正的样本外设计**。严格做法见 R1-4 第 1 项。

## R2-2 本轮发现的新问题（含我自己的一处旧结论错误）

### ❗ 问题 1（严重，已修复）：第 1 轮"正交化残差因子仍含独立信息"的结论**不成立**

第 1 轮我把 `R_F2_超配Z_残差`、`R_F3_超配分位_残差`、`R_F4b_动量Z_残差` 定为"一等因子"，

### ❗ 问题 2（严重，已修复）：`perf_series` 波动率被重复 ×100（长期休眠的 Bug）

组合层报告第一次展示波动率时，输出 **1456.91%**。定位为 `backtest.perf_series`：

```python
vol = x.std(ddof=1) * 2      # x 单位已是 %，故 vol 已在 % 量纲
...
return dict(..., vol=vol * 100, ...)   # ← 又乘了 100
```

正确值应为 **14.57%**。该函数此前只被用于取 `ann / maxdd / sharpe`，
`vol` 字段从未被展示，因此这个错误**静默存活了两轮**。

**修复**：`vol=vol`（去掉 ×100），并加注释说明"此处不得再 ×100"。
影响范围：仅 `vol` 字段本身；`sharpe` 用的是 ×100 之前的局部变量，未受影响。

> 教训与第 1 轮的正交化 Bug 同源：**一个从未被展示的输出字段，不会被任何断言捕获。**
> 本轮起的对策是把"首次展示某字段"当作一次回归测试。

它们不是拥挤度风险信号，而是事实上的动量信号。若不看方向、只报"多空年化"，会得到完全错误的解释。

### 问题 5：同一因子在两个基准下超额符号相反

F15 轮动策略对**等权 31 行业**基准：超额净 **+2.63%**（IR +0.90）；
对**沪深300 动态权重**基准：超额净 **−0.92%**（IR −0.22）。

原因：沪深300 在留出期自身重仓了表现最好的电子（权重 8% → 19%），
等权行业基准是**弱基准**。只报有利的那个是误导，故裁决表里两个基准并列。
F15 因此被评为 **A−（仅胜等权基准）** 而非 A。

## R4-2 R4-A 冲击成本与策略容量（本轮补上的最关键缺口）

此前 R1–R3 的所有净收益都只用**固定 20bp 双边**成本。本轮用**行业季度成交额**
（31 行业 × 34 季度，真实数据）反推参与率：

```
Q_i = |Δw_i| × 组合规模 A            （亿元）
p_i = Q_i / (T_i × h)                 T_i = 行业季度成交额，h = 流动性折损
c_i = max(k × sqrt(p_i), 5bp)         k 校准为 p=1% → 15bp 单边
成本(占组合) = Σ_i (Q_i × c_i) / A
```

**为什么用 sqrt**：冲击成本对交易量是凹函数（Almgren-Chriss 经典结论），
线性假设会严重高估大单、低估小单。**为什么设 5bp 下限**：纯 sqrt 在 p→0 时成本→0，
但真实交易永远有价差与佣金。

| 组合规模 | 平均单期成本 | 毛年化 | 净年化 | 超额净（几何） | IR |
|---|---|---|---|---|---|
| 10 亿 | 0.74 bp | 7.71% | 7.68% | +2.63% | 0.89 |
| 100 亿 | 0.74 bp | 7.71% | 7.68% | +2.63% | 0.89 |
| 1,000 亿 | 0.74 bp | 7.71% | 7.68% | +2.63% | 0.89 |
| **3,000 亿** | **0.74 bp** | 7.71% | 7.68% | **+2.63%** | 0.89 |

**敏感性（h＝流动性折损，k＝冲击系数）**——规模 3,000 亿元时：

| h \ k | 10 | 15 | 20 | 30 |
|---|---|---|---|---|
| 1.00 | 0.74 | 0.74 | 0.74 | 0.75 |
| 0.20 | 0.74 | 0.76 | 0.79 | 0.88 |
| **0.05** | 0.79 | 0.88 | 1.01 | **1.32** |

对应超额净年化几乎不动（2.62% ~ 2.64%）。

**两条结论（都必须引用）**：
1. **容量不构成本策略的约束**——即使假定只能吃到行业成交额的 **5%**（极端收缩）
   且冲击系数翻倍，成本仍仅 1.32bp/期，超额几乎不变。行业轮动的可扩展性远超预期。
2. **此前 20bp 固定假设 = 2.95bp/期，是建模成本的 4.0 倍**
   → **R1–R3 的所有扣费结论都是保守下限**（成本被高估，实际优于报告值）。

> 诚实说明：这一结论与我在 R3 计划里的预期相反。我原以为"容量是最缺的一环"，
> 实测发现容量**极宽松**，真正的约束是**固定摩擦成本**（价差/佣金），不是冲击。

## R4-3 R4-B 因子动量：本项目唯一"方向完全一致"的信号

R3 的 walk-forward 发现"挑设定的流程"样本外不显著，但按时间区块**单调上升**
（−0.032 → +0.095 → +0.125）。这提示扩窗选择在**追逐近期有效的因子**。
本轮把这件事本身当作信号来检验：逐期在**因子之间**做秩相关——
"过去 N 季 IC 高的因子，下一季 IC 是否也高"。

| 回看窗口 | 观测期数 | momIC 均值 | NW t | p 值 | 正比例 | 结论 |
|---|---|---|---|---|---|---|
| 4 季 | 23 | **+0.2159** | **3.561** | **0.0017** | 73.9% | 显著为正 |
| 8 季 | 23 | **+0.2663** | **3.130** | **0.0049** | 78.3% | 显著为正 |

**三档窗口全部显著**，且最小 p=0.0017 通过 Bonferroni（0.05/3 = 0.0167）——

基准 +4.64%、超额净（算术）**+1.92%**、**IR 0.76**、胜率 62.1%、平均换手 9.4%。

### 但稳健性检验把它大幅拉回现实

## R4-4 R4-C 多因子正交组合：**反面结论**

用 Gram-Schmidt 逐期截面正交化 + 设计窗 IC_IR 加权，把 F15 / F3d / F2d / F13 / F12s
合成 F18：

| 因子 | 设计窗符号 | 权重 | 原始 IC_IR | 正交后 IC_IR |
|---|---|---|---|---|
| F15_拥挤背离 | −1 | 0.231 | −0.452 | **+0.452** |
| F3d_超配分位_动态基准 | +1 | 0.413 | +0.493 | +0.344 |
| F2d_超配Z_动态基准 | +1 | 0.299 | +0.447 | **−0.114** |
| F13_筹码盈利比例 | +1 | 0.013 | +0.124 | **−0.049** |
| F12s_配置系数_静态基准 | −1 | 0.045 | −0.202 | +0.160 |

**F18 结果：IC +0.0726、IC_IR +0.286、NW t +1.684、p 0.1052。**
对比单因子 F15（IC_IR **0.452**）—— **多因子正交组合反而系统性稀释**：
正交化的代价是 F2d/F13 的增量信息几乎归零，但它们仍占走 31% 权重。

**结论：不走多因子合成，保持 F15 单因子 + 因子动量动态调权。**
（这也与 R3 的二层正交化发现一致：同族因子在正交后信息归零。）

## R7-1 解决遗留边界：F2/F3/F4b/F15 长历史版解锁（2026-10-03 夜）

只取动态权重段，排除静态口径漂移），据此算长历史扩窗因子：

| 因子 | 含义 | 有值区间 | IC（t+1） | t_NW | p |
|---|---|---|---|---:|---:|
| F2e_超配Z_长历史 | 相对自身历史的极端度 | 2024Q1 起 9 期 | **+0.161** | 5.77 | 0.0007 |
| F3e_超配分位_长历史 | 历史分位 | 2023Q4 起 15 期 | +0.101 | 2.04 | 0.061 |
| F4be_动量Z_长历史 | 边际资金方向 | 2024Q2 起 7 期 | +0.058 | 1.75 | 0.141 |
| F15e_拥挤背离_长历史 | 新增拥挤（绝对高、历史不极端） | 2024Q1 起 9 期 | **−0.109** | −2.48 | 0.042 |

### 关键结论（本轮最重要的新发现）
1. **F2e 超配 Z 长历史 IC +0.161（t=5.77, p<0.001, 胜率 87.5%）**：强「趋势延续」证据——
   「相对自身历史越极端，未来越强」。这与主口径 F3（+0.115）方向一致、强度更高。
2. **F15e 拥挤背离 IC −0.109（t=−2.48, p=0.042，样本外 −0.224 更强）**：本项目
   **第一次**得到与「拥挤=风险」先验**方向一致且显著**的证据——真正危险的不是
   「已经很挤」，而是「绝对超配高、但相对自身历史还不极端」的**新增拥挤**。
3. 两个方向的信号并存不矛盾：存量拥挤是趋势确认（动量），新增拥挤是风险预警（反转）。

### 最重要的发现（诚实修正）
把超配历史从 17 期延到 36 期后，长历史扩窗因子的 IC 观测从 8 期提升到 27~30 期，
结果发生了**方向性变化**：

| 因子 | 8 期样本 IC | 36 期样本 IC | 判定 |
|---|---:|---:|---|
| F2e 超配 Z | +0.161（p=0.0007） | +0.024（p=0.50） | 伪显著 → 不显著 |
| F3e 超配分位 | +0.101（p=0.061） | +0.059（p=0.11） | 边际 → 不显著 |
| F4be 动量 Z | +0.058（p=0.14） | +0.037（p=0.34） | 不显著 |
| F15e 拥挤背离 | −0.109（p=0.042） | +0.003（p=0.94） | **方向反转、彻底消失** |

**结论**：R7-1 报告的「F2e +0.161 显著、F15e −0.109 首次支持拥挤=风险」是**小样本伪显著**
（受 2026 电子单一行业极端值驱动）。样本延到 36 期后全部消退。这恰恰证明了 36 期标准
的价值——它筛掉了短样本的虚假信号。
